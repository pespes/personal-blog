## Purpose & stack

A personal blog (author: Peter Esveld) built on **Astro v6** (AstroPaper template), deployed as a fully static site to **Cloudflare Pages**. Styling is **Tailwind CSS v4** (configured via `@import "tailwindcss"` and an `@theme inline` block in `src/styles/global.css`, not a `tailwind.config.js`). Long-form content is styled with the `@tailwindcss/typography` plugin (`.app-prose`). Fonts load through Astro's top-level `fonts` API. Content is authored in Markdown/MDX (`src/data/blog/`) with an optional Keystatic CMS at `/keystatic`. **Design tokens and the component library are authored in Figma and treated as the source of truth**, synced into the repo via `/figma-sync`.

## Conventions Claude Code must follow

- **Token format:** DTCG (`$type` / `$value` / `$extensions`) in `design/tokens.json`. Figma metadata (variableId, collection, mode, css, scopes) lives under `$extensions."com.figma"`.
- **CSS custom properties:** colors are bare semantic names — `--accent`, `--background`, `--border`, `--foreground`, `--muted` — defined for `:root`/`[data-theme="light"]` and `[data-theme="dark"]`. Fonts: `--font-app` (body/UI) and `--font-display` (headings/display). Tailwind utilities are mapped from these in `@theme inline` (`--color-*`, `--font-*`).
- **Figma variable naming:** slash-grouped so Figma nests them — e.g. `size/100`, `leading/normal`, `weight/semibold`, `tracking/tight`, `family/base`. Text Styles use `Group/Name` (`Heading/H1`, `Body/Default`, `UI/Label`, `Display/Large`).
- **Figma component naming:** slash-grouped (`Icon/GitHub`); variant properties follow the existing set — `State=…` (e.g. Default/Hover/FirstPage), `Size=…` (Large/Small).
- **Layering (primitive → semantic → component):** Figma `Type Primitives` (raw values) → Text Styles (semantic roles that bind primitives) → components apply Text Styles. Colors: `Blog Tokens` (semantic) → CSS custom properties → Tailwind. Keep this order; do not collapse layers.
- **Typeface roles:** **Inter** = body / UI / caption / label / quote (the workhorse). **Sora** = display **and** headings. **JetBrains Mono** = inline code. (Sora was originally "display only"; extended to headings on 2026-07-02.)
- **Nested blog dirs:** subdirectories prefixed with `_` (e.g. `_releases/`) are excluded from URL slugs.

## Guardrails — do not do this

- **Don't hand-edit inside the `/* figma-tokens:start … end */` markers** in `src/styles/global.css`. It is generated; hand edits are reported as `code-drift` by `pnpm figma:sync --check`. Edit in Figma and re-sync.
- **Don't hand-edit `design/tokens.json`, `design/components.json`, `design/design-system.generated.md`, or the sync-state files.** Figma is the source of truth; use `pnpm figma:sync`.
- **Don't bind `lineHeight` or `letterSpacing` to variables in Figma Text Styles.** On this Figma version, binding coerces the unit `PERCENT → PIXELS` and breaks scaling. Keep those two as literal percent values; only `fontSize`, `fontFamily`, and `fontWeight` are variable-bound.
- **Don't hardcode hex colors in Figma components/icons.** Bind fills/strokes to the `Blog Tokens` color variables (e.g. `foreground` = VariableID:5:4) so light/dark works.
- **Don't use Sora for body/UI text**, and don't use Inter for headings — see the typeface roles above.
- **Don't bump `zod` past `4.3.6`** (pinned via `overrides` in `pnpm-workspace.yaml`; Astro 6.4.x needs the v3-style `z.function().optional()` API). Node must be **≥ 22.12.0**.
- **Don't reintroduce the X social link.** It was removed from `SOCIALS` in `src/constants.ts` and from the Figma `Socials`/Footer on 2026-07-02. (The separate "share to X" button in `SHARE_LINKS` was intentionally kept.)
- **Don't assume headings render in Sora in the shipped site yet** — the Sora-headings + full type-scale decision currently lives in Figma only; it is not yet wired into `global.css` (see Open decisions).
